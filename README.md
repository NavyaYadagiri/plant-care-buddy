# 🌿 Plant Care Buddy

A friendly houseplant companion that tracks watering, shows each plant's mood, and gives care tips, so no plant gets forgotten.

![App screenshot](screenshots/home.png)

## Why I built this
I have 7–8 houseplants and kept losing track of which one needed water when.
I wanted a simple, visual app where each plant has a name, a photo, and a mood
that tells me at a glance if it needs attention.

## Features

### ✅ Current (v1)
- Add plants with a photo, name, and species
- Personal plant collection, each plant with a unique ID
- Custom watering schedule per plant
- Mood indicator: 😊 on schedule · 😐 due today · 😢 overdue
- Tap any plant for care tips

### 🔜 Coming soon
- **v2:** AI plant identification from a photo, with auto-generated care tips (Claude API)
- **v3:** Voice mode, drag-and-drop emoticons, plant health streaks

## Tech stack
- React + Vite
- Local storage (database planned for v2)
- Claude API (planned for AI features)

## Getting started

```bash
git clone https://github.com/NavyaYadagiri/plant-care-buddy
cd plant-care-buddy
npm install
npm run dev
```

Then open the local link shown in your terminal (usually http://localhost:5173).
